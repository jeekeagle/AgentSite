复制下面这段，发给你的编程助手：

你的编程助手

›帮我用 Python 装好 openai-agents，配上 OpenAI / DeepSeek 的 API Key，写一个能调用本地文件系统的 Agent：当我说"整理桌面"时，它能扫描 Downloads 文件夹，按扩展名归类到 Docks、Documents、Pictures、Others 子文件夹里，给我一份清单。

或者在终端里跑：

pip install openai-agents

同意计划，然后让你的编程助手跑起来。

适配你的平台： Windows (PowerShell) macOS Linux

工作原理

智能体干活的本质是：一个会说话的循环。它会想「接下来做什么」、调工具、看结果、再决定下一步。课程教你搭起这个循环。

  1. 问一个问题

    把你的资料、代码、问题扔给它。

  2. 它动手查

    它会读文件、调 API、查数据库，把证据找出来。

  3. 它回答，再帮你改

    你看着它给的结果，决定下一步怎么走。

示例 01 · Chrome 小恐龙游戏

为什么小恐龙越跑越快？

打开 Chrome 离线小恐龙，让 Agent 找出「速度」藏在哪儿，再试着改一下。

  1. 1. 问它速度

    跟你的编程助手说：「看看 Chrome 离线小恐龙游戏，为什么它越跑越快？」

  2. 2. 找速度规则

    让它调工具打开恐龙游戏的代码，找那个会随分数上涨的「速度变量」。

  3. 3. 跑起来看看

    让它改一下这个变量，重新跑一遍，看你玩得动还是玩不动。

示例 02 · Windows 计算器

复刻计算器的 % 按钮。

让 Agent 找出 % 按钮背后的两条规则，再用 Python 自己写一个。

  1. 1. 问它 % 按钮

    问 Agent：Windows 计算器的 % 按钮是怎么算出 200 + 10% = 220 的？

  2. 2. 找两条规则

    让它拆出计算器里的两套逻辑：200 + 10% 是一回事，200 + 10 % 100 是另一回事。

  3. 3. 试试 % 按钮

    用 Agent 写出来的 Python 函数，跑两个 case 验证，再决定你信不信它。
