把这段发给你的编程助手

复制下面这段，对 Claude / GPT / Cursor 任何一个发出去，30 秒就有你的第一个 Agent 跑起来。

你的编程助手

›帮我用 Python 写一个能调用本地文件系统的 Agent：当我说"整理桌面"时，它能扫描 Downloads 文件夹，把文件按扩展名分类到 Docks、Documents、Pictures、Others 子文件夹里，然后给我一份清单。

它会跑出类似这样的结果：

$ pip install openai-agents
$ export OPENAI_API_KEY=sk-...
$ python 01_first_agent.py

[Planner] 分析意图：整理桌面
[Tool] list_dir(Downloads) → 47 个文件
[Tool] mkdir(Docks) mkdir(Documents) ...
[Reflect] 检查：是否有冲突？文件名是否重复？
[Done] 已归类 47 个文件，2 个被跳过（同名）
