三分钟上手

你的第一个 Agent

复制下面这段发给你的编程助手 / 终端，先跑通再说。

你的编程助手

›帮我用 Python 写一个能调用本地文件系统的 Agent：当我说"整理桌面"时，它能扫描 Downloads 文件夹，把文件按扩展名分类到 Docks、Documents、Pictures、Others 子文件夹里，然后给我一份清单。

→ 这是第一课的作业题 0。答案在 快速开始。

$ pip install openai-agents
$ export OPENAI_API_KEY=sk-...
$ python 01_first_agent.py

[Planner] 分析意图：整理桌面
[Tool] list_dir(Downloads) → 47 个文件
[Tool] mkdir(Docks) mkdir(Documents) ...
[Reflect] 检查：是否有冲突？文件名是否重复？
[Done] 已归类 47 个文件，2 个被跳过（同名）

运行日志长这样：思考 → 行动 → 反思 三步循环。

学习路径

三种学法，挑一个

按你的时间、目标和背景选一个，不强求全做。

🥚 零基础尝鲜

只想知道 Agent 是什么、能干嘛、要花 4 周的零碎时间。

  • 看 1、2、10 章讲义
  • 用扣子 / Dify 拖一个 Agent 出来
  • 不写代码，做完能吹一年

零基础路径 →

🐣 工程师入门

会写代码，想亲手搭一个能用的 Agent。

  • 完整做 1–8 章 + 作业
  • 选 9–12 中一章深入
  • 12 周末拿出自己的 demo

工程师路径 →

🐓 产品 / 创业者

不懂代码，但想用 Agent 做产品 / 提效 / 创业。

  • 看 1、3、7、10、11 章
  • 低代码搭一个能上线的最小版本
  • 学怎么定价、怎么管、怎么避坑

工具与生态

你会用到的几样东西

课程里所有例子都在这三类工具里，挑顺手的就行。

大模型 API

OpenAI、Anthropic、Google、DeepSeek、智谱、月之暗面——任选一家。

openai · anthropic · google-genai

Agent 框架

OpenAI Agents、LangGraph、CrewAI、AutoGen——课程主用前两个。

openai-agents · langgraph

低代码平台

不写代码也能搭：Dify、扣子（Coze）、Flowise、n8n。

dify · coze · flowise

向量数据库

chroma · qdrant

langfuse · phoenix

评估

promptfoo · braintrust
