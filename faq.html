关于 Agent 本身

Agent 和大模型（ChatGPT）到底有什么区别？

两分钟答案：大模型是一个会说话的函数，给它输入它就吐字；Agent 是一个会做事的循环，它会想「我该用什么工具」→ 调用工具 → 看结果 → 再决定下一步。一个会说话，一个会做事。

打比方：大模型是一个百科全书，Agent 是一个会查这本百科全书的图书管理员。管理员还能打电话、订机票、写代码——只要你把工具给它。

更长版本在这里。

Agent 和「工作流」（Workflow）、RPA、机器人有什么区别？

工作流和 RPA 是人定义好每一步，机器照做；Agent 是机器自己决定每一步。前者死板但稳定，后者灵活但不可控。现实中好的系统往往两者结合：人定义边界，Agent 在边界内自由发挥。

为什么 2023 年之后 Agent 这个词突然火了？

三件事撞在了一起：(1) GPT-4 这一代模型终于能稳定做多步推理；(2) Function Calling 接口标准化了，工具调用变成了「一行代码」；(3) LangChain 等框架让搭一个 Agent 从 3 周变成了 3 小时。三件事凑齐，「Agent」才从论文里的概念变成了人人都能搭的东西。

Agent 真的能干活吗？会不会只是噱头？

看场景。在「明确规则 + 大量重复 + 风险可控」的活上，Agent 已经比人便宜；在「模糊目标 + 需要审美 + 高风险」的活上，Agent 还是辅助。课程第 10 章会按行业拆开讲。

以后 Agent 会取代人吗？我学这个还有意义吗？

比起「Agent 取代人」，更可能发生的是「会用 Agent 的人取代不会用 Agent 的人」。这门课不是教你对抗 AI，是教你和它一起干活。不会用 AI 的同学，毕业后会发现自己在和会用 AI 的同学竞争同一个岗位。

关于课程

我是文科生 / 非计算机专业，能学吗？

能，但要走「🥚 零基础路径」或「🐓 产品路径」。这两个路径不需要写代码也能完成 90% 的学习任务，最后 10% 的代码作业可以找队友帮你写、你帮他们理解业务——这正是课程项目组队的本意。

课程有期中期末吗？

有一次期中 demo（第 7 周前），一次期末项目（第 12 周）。每周还有一次小作业。具体看大纲。

我可以旁听吗？

可以。所有讲义、所有代码、所有 showcase 都公开。旁听同学不需要交作业，但欢迎参加 Office Hours 和讨论区。

课程内容会更新吗？

每学期开学前更新一次。Agent 领域变化很快，去年的最佳实践今年可能就是反模式。所有变更会写进 更新日志。

关于作业与项目

作业可以用 AI 帮忙做吗？

可以用，但有两个硬性要求：(1) 你必须能讲清楚每一行代码 / 每一个提示词为什么要这么写；(2) 你必须在 README 里写明哪部分是 AI 写的、你改了哪里、为什么改。把 AI 当队友，不当替身。

项目必须用最新最强的模型吗？

不必。评分看问题价值、技术深度、可用性，不看你用的是 GPT-5 还是本地 7B 模型。预算紧张的同学可以用 DeepSeek / Qwen / 智谱免费额度，作业完全够用。

项目 idea 被同学抢先了怎么办？

这是好事——说明这个 idea 真有问题。你们可以合并组，或者各做各版相互对比。「同一个 idea 不同实现」的对比展示，比孤零零一个项目分数更高。

关于 AI 工具本身

用国产大模型还是 OpenAI / Anthropic？

取决于场景。复杂推理（数学 / 代码 / 规划）目前 GPT-4 / Claude 还领先；中文写作、角色扮演、垂直行业知识，DeepSeek / Qwen / 智谱已经够用且更便宜。课程不绑定任何一家，按性价比选。

我的数据会上传到模型公司吗？

看条款。OpenAI / Anthropic 默认不拿你的数据训练（API 调用），但会留 30 天用于安全审计。敏感数据请用本地模型（Ollama + Qwen / Llama）或私有部署。

本地能跑得动 Agent 吗？

看模型。7B 模型 + 简单工具调用，4090 显卡 / M2 Max 都能跑。70B 模型要双 A100 / H100，或者上量化方案。课程里大部分例子用 7B–14B 跑得动。
