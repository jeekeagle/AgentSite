为什么开这门课

2023 年之后，「Agent」这个词从论文里走出来，到了所有人嘴边。但绝大多数介绍它的内容，要么是给研究员的论文综述，要么是给老板的 PPT 故事，没有一份给「想用它但还没用过」的人。

这门课想做的就是这件事：一份对所有人友好、对工程师也尊重的入门课。文科生能听懂、能用上；工科生能上手、能搭出来。

我们相信：未来五年最被需要的技能，不是「懂 AI 原理」，是「会用 AI 干活」。这门课就是冲着后者去的。

课程目标

学完这门课，你能——

  • 用 5 分钟讲清楚 Agent / 大模型 / 工作流的区别。
  • 亲手搭一个能调用 5 个工具的本地 Agent。
  • 用 RAG 让 Agent 读你的私人资料。
  • 用多智能体编排搭一个「研究员 + 写手 + 审稿人」小队。
  • 写出评测脚本，看清 Agent 哪里好、哪里坏。
  • 意识到 Agent 的三类风险（注入 / 越权 / 幻觉），并做出防御。
  • 用低代码工具搭一个能上线的最小版本。
  • 带领一个 3 人小组，在 4 周内交付一个真人在用的 Agent。

两分钟区别：Agent 和大模型

这是这门课学生最常问的问题，也是最重要的概念。展开讲一讲。

大模型 = 一个会说话的函数

输入一段文本，输出一段文本。它没有「世界」的概念，没有「接下来做什么」的概念。它的全部能力在「读一段话、写一段话」。

用起来像：开一个对话框，你说一句，它回一句。它不会主动去查邮件、读文件、订机票——除非你把那些信息贴进对话框。

Agent = 一个会做事的循环

它不仅会说话，还会想接下来做什么，然后调用工具去做，看结果，再决定下一步。它的能力来自「思考 + 工具 + 记忆」的循环，不只是模型本身的文字能力。

用起来像：你说「帮我订明天去上海的差旅」，它自己去查日历、查航班、查酒店价格、问你偏好、发邮件确认。人不被锁在对话框里。

一个具体的例子

你说：「我们公司去年招了多少人？」

大模型（ChatGPT）的反应

它会说：「抱歉，我没有你公司的数据，无法回答。」——它说对了，但没用。

Agent 的反应

  1. 想：「用户想知道公司去年招聘数据，我需要查 HR 系统。」
  2. 调用工具：query_hr_system(table='recruits', year=2024)。
  3. 得到结果：「去年共入职 47 人，其中工程师 28 人。」
  4. 回答：「去年你们公司入职 47 人，工程师 28 人。要看具体名单吗？」
  5. 如果你说「要」，它再调一次工具，把名单拉出来。

区别不在「会不会说话」——两个都会说话。区别在「会不会自己去拿数据」。Agent 的关键不是更聪明，是有手有脚。

记住一句话：大模型是把嘴给电脑，Agent 是把整个实习生给电脑。
