三十分钟跑通

快速开始

装环境、配 Key、跑示例、读懂 trace。本节假设你是 macOS / Linux 用户；Windows 用户请参考末尾的 WSL 说明。

1. 准备环境

三样东西：Python ≥ 3.10、一个 API Key、一个顺手的 IDE。

1.1 Python 与虚拟环境

$ python --version          # 确认 ≥ 3.10
$ python -m venv .ada-venv  # 建虚拟环境
$ source .ada-venv/bin/activate
$ pip install --upgrade pip

1.2 装课程 SDK 与基础依赖

$ pip install openai-agents python-dotenv rich httpx
$ pip freeze > requirements.txt

1.3 配置 API Key

选一家就行，不要把 Key 写进代码。

# .env（项目根目录，自己建，gitignore）
OPENAI_API_KEY=sk-...
# 或者
ANTHROPIC_API_KEY=sk-ant-...
# 国内
DEEPSEEK_API_KEY=sk-...
ZHIPUAI_API_KEY=...

国内用户：DeepSeek、智谱、月之暗面、Kimi、Qwen 都有兼容 OpenAI 协议的接口。改一行 base URL 就能用。

2. 跑通第一个 Agent

建一个文件 01_first_agent.py，把下面这段贴进去。

import asyncio
from agents import Agent, Runner, function_tool
from dotenv import load_dotenv

load_dotenv()

@function_tool
def get_weather(city: str) -> str:
    """查某城市今天天气（演示用，返回固定值）。"""
    return f"{city} 今天 24°C，多云转晴。"

agent = Agent(
    name="WeatherBot",
    instructions="你是天气助理。用户问天气就调用 get_weather；问别的就礼貌说不归你管。",
    tools=[get_weather],
)

async def main():
    result = await Runner.run(agent, "北京今天天气怎么样？")
    print(result.final_output)

asyncio.run(main())

运行：

$ python 01_first_agent.py
北京今天 24°C，多云转晴。

跑出来了？恭喜，你已经搭好了一个会调用工具的 Agent。

3. 读懂 trace

只看 final_output 远远不够——你要看 Agent 到底想了什么、为什么调了这个工具、什么时候停下来的。开 trace：

export OPENAI_AGENTS_TRACE=1
python 01_first_agent.py
# 或者用 Langfuse / LangSmith 看更详细的 trace（课程第 8 章会讲）

一个好的 trace 长这样：

[Turn 1] user:        北京今天天气怎么样？
[Turn 1] assistant:   thought="用户想知道北京天气，应该调用 get_weather"
                     tool_call=get_weather(city="北京")
[Turn 1] tool:        get_weather → "北京 今天 24°C，多云转晴。"
[Turn 1] assistant:   final="北京今天 24°C，多云转晴。"

看到 thought / tool_call / final 三件事，就是一个完整的 Agent 循环。后续所有复杂 Agent——RAG、记忆、多智能体——都是这个循环的扩展。

🥚 零基础路径 · 4 周尝鲜

如果你只想知道 Agent 是什么、能干嘛、不想写代码，按这条走：

  1. 第 1 周：看第 1、2 章讲义；用 ChatGPT / Claude 玩「角色提示」，做三个性格不同的助理。
  2. 第 2 周：注册扣子（Coze）或 Dify，拖一个能查天气的 Bot，发布到飞书 / 微信。
  3. 第 3 周：给你的 Bot 接一个知识库（你的笔记本 / 公众号历史文章），让它答得出你专业的问题。
  4. 第 4 周：找一个你日常重复的事（整理周报、查资料、回邮件），用 Bot 替你跑一次，写一篇复盘。

四周后你应该能向朋友讲清楚「Agent 是什么、它和大模型有什么区别、我用它做了什么」。

🐣 工程师路径 · 完整 12 章

如果你会写代码，想亲手搭一个能上线的 Agent：

  1. 完整跑完第 1–8 章作业，每章至少交一次 PR。
  2. 第 7 章前提交期中 demo：一个能完成真实任务的本地 Agent + 5 分钟讲解视频。
  3. 第 9–11 章选两章深入（推荐：评估 + 安全；或多智能体）。
  4. 第 12 章前交期末项目：4 周组队项目。

期末目标：你的 GitHub 上有一个 100+ star 的 Agent 仓库，或者你的项目已经被真实用户在用。

🐓 产品 / 创业者路径

不懂代码但想用 Agent 做产品 / 提效 / 创业：

  1. 看 1、3、7、10、11 章讲义，重点是「能做什么 / 不能做什么 / 适合谁」。
  2. 第 3 周前用低代码搭一个能跑通的最小版本（MVP）。
  3. 第 5 周前找 5 个真实用户试用，记录反馈。
  4. 第 9 章必看：把安全 / 隐私 / 权限这三件事想清楚。
  5. 期末项目优先做「让 100 个人真的在用」的小工具，而不是功能齐全的大平台。

常见问题——「我的 Agent 想法会不会太天真？」——几乎都会。第四章讲义里有一份《Agent 想法体检清单》，拿去用。

常见小问题

我电脑是 Windows，能跑吗？

可以。装 WSL2（Ubuntu），然后按 macOS / Linux 的步骤来。Windows 原生 Python 也行，但 shell 命令会有差异。课程所有代码都在 Linux 测过，跨平台没问题。

我没有 OpenAI Key，能学吗？

能。课程默认支持 OpenAI / Anthropic / Google / DeepSeek / 智谱 / 月之暗面 任选一家。某些高级评测功能（比如 trace 详情）需要 OpenAI 或 Anthropic，但作业都能完成。

我不会 Python，能学吗？

能，但要愿意一周内学会基础语法。建议直接看官方教程的「前 5 章」，边学边做第 2 章作业。如果完全不想碰代码，请走「零基础路径」。

跑通了，但还是不知道 Agent 和 ChatGPT 区别在哪？

好问题。看第一章讲义里的「两分钟区别」一节，或者读这篇 《Agent 和大模型有什么区别》。

作业不会做怎么办？

先在课程 Discussions 搜，搜不到再发新帖。助教承诺 24 小时内回复。别憋着——这门课大部分「卡住」都不是你的问题，是文档没说清楚。
