总体结构

课程分四个阶段：地基（第 1–2 章）讲清楚是什么、为什么；骨架（第 3–6 章）讲工具、记忆、规划、检索四大能力；装修（第 7–9 章）讲多智能体协作、评估、安全；落成（第 10–12 章）讲应用、低代码、课程项目。

阶段章节目标产出
地基1 – 2理解 Agent 与 LLM 的关系一份「什么是 Agent」的笔记
骨架3 – 6搭起单个 Agent 的核心循环一个本地能跑通的多工具 Agent
装修7 – 9让 Agent 可评测、可协作、可控多智能体原型 + 评测脚本
落成10 – 12把 Agent 变成产品 / 项目4 周组队项目 + 公开 demo

章节详情

01

智能体概述：从工具到协作者

📅 第 1 周⏱ 90 分钟讲义 + 60 分钟实验🎯 概念 / 心智模型

概念心智模型历史

讲清楚「Agent」这个词在不同语境下的含义：哲学意义、心理学意义、AI 意义。我们这里指的是哪一种？为什么 2023 年之后这个概念突然火了？Agent 和传统软件、和大模型聊天、和机器人有什么不一样？

课后阅读：《人工智能：一种现代方法》第 2 章「智能体」节；Minsky《心智社会》序章。

02

大模型基础与提示工程

📅 第 2 周⏱ 90 分钟讲义 + 90 分钟实验🎯 提示工程

LLMPromptTokenFew-shot

半小时回顾 Transformer 与预训练，然后花一个半小时写提示词。讲清楚：系统提示 / 用户提示、温度、top-p、结构化输出（JSON mode）、少样本提示、思维链。这一章不写代码，只调提示词，让每个人做出一个像样的「私人助理」。

作业：用同一个底层模型，做出三个性格迥异的 Agent（老师 / 损友 / 顾问），对比效果。

03

工具调用：让模型动手

📅 第 3 周⏱ 90 分钟讲义 + 120 分钟实验🎯 Function Calling

Function CallingToolsJSON Schema

Function Calling 是 Agent 之所以是 Agent 的关键。这一章用 OpenAI / Anthropic 的工具调用 API 做一个能查天气、查日历、发邮件的助理。重点不是 API 长什么样，而是「怎么定义工具的边界」——输入校验、错误处理、危险操作授权。

作业：给 Agent 接 5 个本地工具（文件 / shell / 浏览器 / 数据库 / 邮件），让它完成一个真实任务。

04

RAG：让 Agent 读你的资料

📅 第 4 周⏱ 90 分钟讲义 + 120 分钟实验🎯 检索增强生成

RAGEmbeddingVector DBChunking

讲清楚为什么「模型不知道的事实」必须靠检索补，而不是靠更大的模型。亲手做一个能读你整个课程 PPT 的 Agent：加载 → 切片 → 嵌入 → 检索 → 回答 → 引用。重点是切片策略与评测，不是向量数据库本身。

作业：选一份你本专业的资料（课本 / 论文 / 规章），做一个能回答「按第几章第几节讲的」的 Agent。

05

记忆与上下文管理

📅 第 5 周⏱ 90 分钟讲义 + 90 分钟实验🎯 Memory

MemoryContextSummarization

为什么 LLM「记不住事」？这一章拆开短期记忆（context window）、长期记忆（向量库 + 摘要）、工作记忆（任务状态）。讲清楚「压缩」「遗忘」「回看」三种机制，以及它们怎么影响 Agent 的行为。

作业：让 Agent 陪你聊 50 轮后，还能准确复述你的偏好、你的项目目标、你拒绝过的方案。

06

规划与推理：ReAct、Plan-and-Execute、反思

📅 第 6 周⏱ 90 分钟讲义 + 120 分钟实验🎯 Reasoning Loop

ReActPlanningReflection

Agent 之所以会做事，是因为它有一个循环：思考 → 行动 → 观察 → 再思考。本章拆解 ReAct、Plan-and-Execute、Reflexion 三种范式。亲手用 LangGraph 搭一个能拆解「帮我订明天去上海的差旅」这种模糊任务的 Agent。

作业：选一个真实任务（订餐 / 抢课 / 整理笔记），用三种范式各做一遍，对比成功率和成本。

07

多智能体协作与编排

📅 第 7 周⏱ 90 分钟讲义 + 120 分钟实验🎯 Multi-Agent

Multi-AgentCrewAIOrchestration

什么时候该拆成多个 Agent？什么时候拆开反而更糟？讲清楚「角色分工」「消息路由」「冲突仲裁」「共享记忆」四个工程问题。用 CrewAI / LangGraph 搭一个「研究员 + 写手 + 审稿人」小队，让它自己开会出一篇综述。

作业：三人为一组，搭一个多 Agent 系统完成一个 5 步以上的真实任务。

08

评估与可观测性

📅 第 8 周⏱ 90 分钟讲义 + 120 分钟实验🎯 Eval & Observability

EvalTracingLangSmithLangfuse

怎么知道 Agent 干得好不好？讲清楚三类评测：端到端任务成功率、单步准确性、人评质量。介绍 LangSmith、Langfuse、Phoenix 这些工具，亲自给一个 Agent 加上 trace。讲清楚为什么「能跑」不等于「能上生产」。

作业：给第三章做的 Agent 加上完整 trace，写一份 200 字的事后分析。

09

安全、隐私与对齐

📅 第 9 周⏱ 90 分钟讲义 + 60 分钟实验🎯 Safety

SecurityPrompt InjectionHuman-in-the-loop

讲清楚三类风险：提示注入（你的 Agent 被一份 PDF 控制了）、权限越权（Agent 删了不该删的文件）、幻觉传播（Agent 把错的答案写进了数据库）。讲清楚为什么「人类在回路」不是可选项，以及为什么「能干的 Agent」比「能说的 Agent」危险得多。

作业：在你的 Agent 上找出三个真实的注入风险，并提出防御方案。

10

行业应用：办公、编程、教育、客服

📅 第 10 周⏱ 4 场客座讲座🎯 Real Cases

OfficeCodingEducationSupport

邀请四到六位在不同行业用 Agent 的从业者来做 30 分钟客座讲座，每场讲一个真实项目：怎么开始的、踩过什么坑、最后跑成了什么样、用户反馈是什么。学生提前看材料、准备三个问题，讲座后写一页反思。

11

低代码与可视化构建

📅 第 11 周⏱ 90 分钟讲义 + 120 分钟实验🎯 No-Code

DifyCozeFlowisen8n

不写代码也能搭：对比 Dify、扣子（Coze）、Flowise、n8n 四个平台的「能做什么 / 不能做什么 / 适合谁」。亲手用其中一个搭一个能上线的最小版本——能跑、能用、能改。这一章是给「不会写代码但想用 Agent 干活」的同学准备的。

作业：用低代码搭一个内部工具（比如自动整理周报的 Agent），给团队用一周，写复盘。

12

课程项目展示

📅 第 12 周⏱ 公开 demo + 互评🎯 Capstone

DemoPeer Review展示

四周组队项目最终展示。每组 10 分钟 demo + 5 分钟答辩 + 5 分钟互评。评委包括任课教师、助教、邀请的业界评委。优秀项目进入学生作品长期展示，并被推荐到社区。
